# Power BI DAX Measures Reference

This document provides the complete, production-tested **DAX Measures** designed specifically for the `ecommerce_db.orders` table (imported from `Clean_Ecommerce.xlsx`).

---

## 📊 Dataset Schema Overview

- **Table Name**: `orders`
- **Total Records**: `524 rows`
- **Columns**: `Order_ID`, `Order_Date`, `Customer_Name`, `Email`, `Phone`, `City`, `State`, `Product`, `Category`, `Qty`, `Unit_Price`, `Discount`, `Payment_Mode`, `Order_Status`, `Delivery_Date`, `Order_Month`, `Sales`, `Net_Amount`, `Profit`, `Order_Year`, `Order_Day`

---

## 📐 11 Core DAX Measures

### 1. Total Gross Sales
Calculates total gross revenue generated across all transactions.
```dax
Total Sales = SUM(orders[Sales])
```
*Format*: Currency (`₹#,##0.00`)

---

### 2. Total Orders
Counts total unique order transactions.
```dax
Total Orders = DISTINCTCOUNT(orders[Order_ID])
```
*Format*: Whole Number (`#,##0`)

---

### 3. Total Quantity Sold
Calculates total volume of product units sold.
```dax
Total Quantity = SUM(orders[Qty])
```
*Format*: Whole Number (`#,##0`)

---

### 4. Total Unique Customers
Counts total distinct customer profiles.
```dax
Total Customers = DISTINCTCOUNT(orders[Customer_Name])
```
*Format*: Whole Number (`#,##0`)

---

### 5. Average Order Value (AOV)
Measures the average revenue generated per transaction.
```dax
Average Order Value = DIVIDE([Total Sales], [Total Orders], 0)
```
*Format*: Currency (`₹#,##0.00`)

---

### 6. Average Discount Rate
Calculates the average promotional discount percentage applied across orders.
```dax
Average Discount = AVERAGE(orders[Discount])
```
*Format*: Percentage (`0.0%`)

---

### 7. Total Net Revenue
Total sales collected after subtracting promotional discounts.
```dax
Total Net Revenue = SUM(orders[Net_Amount])
```
*Format*: Currency (`₹#,##0.00`)

---

### 8. Total Gross Profit
Cumulative gross profit generated by product sales.
```dax
Total Profit = SUM(orders[Profit])
```
*Format*: Currency (`₹#,##0.00`)

---

### 9. Profit Margin Percentage
Ratio of gross profit to total revenue.
```dax
Profit Margin % = DIVIDE([Total Profit], [Total Sales], 0)
```
*Format*: Percentage (`0.0%`)

---

### 10. Category Sales Contribution Percentage
Computes the percentage contribution of a selected category relative to the entire catalog.
```dax
Category Sales % = 
DIVIDE(
    [Total Sales],
    CALCULATE([Total Sales], ALL(orders[Category])),
    0
)
```
*Format*: Percentage (`0.0%`)

---

### 11. Top Product Sales
Returns the revenue generated by the #1 best-selling product across the catalog.
```dax
Top Product Sales = 
CALCULATE(
    [Total Sales],
    TOPN(1, ALL(orders[Product]), [Total Sales], DESC)
)
```
*Format*: Currency (`₹#,##0.00`)

---

## 🛠️ How to Connect Power BI Desktop to MySQL

1. Open **Power BI Desktop**.
2. Click **Get Data** → Select **MySQL Database**.
3. In the Connection Dialog:
   - **Server**: `localhost:3306`
   - **Database**: `ecommerce_db`
   - **Data Connectivity Mode**: `Import`
4. Enter MySQL credentials:
   - **User name**: `root`
   - **Password**: `Your MySQL Password`
5. Select the **`orders`** table and click **Load**.
6. In the **Model** view, right-click the `orders` table → Click **New Measure** to create each DAX formula above.
